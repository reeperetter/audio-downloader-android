# 🎵 Music Downloader

Android-застосунок для пошуку та завантаження музики з YouTube у форматі `.m4a`.
Написаний на [Flet](https://flet.dev) (Python + Flutter) з використанням [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## Можливості

- 🔍 Пошук треків за назвою або виконавцем
- ▶️ Швидкий перегляд знайденого відео на YouTube (одним дотиком)
- ✅ Вибір кількох треків одночасно (чекбокси + "Обрати все" / "Скинути")
- ⬇️ Завантаження обраних треків у форматі `.m4a` (AAC-аудіо, висока якість, відтворюється практично будь-де)
- 📁 Автоматичне збереження у публічну папку **"Завантаження"** пристрою (без потреби щось обирати вручну)
- 📊 Прогрес-бар і статус у реальному часі під час пошуку/завантаження

## Збірка

Збірка повністю автоматизована через **GitHub Actions** — досить запушити зміни в гілку `main`/`master`,
і в розділі **Actions** з'явиться готовий підписаний `.apk` як артефакт збірки.

### Одноразове налаштування підпису APK

Щоб Android не сприймав кожну нову збірку як "інший застосунок" (і не вимагав видаляти стару версію
перед встановленням нової), APK підписується постійним release-ключем. Потрібно один раз додати
4 секрети в **Settings → Secrets and variables → Actions**:

| Секрет | Опис |
|---|---|
| `ANDROID_SIGNING_KEY` | keystore-файл (`.jks`), закодований у base64 |
| `ANDROID_KEY_ALIAS` | псевдонім ключа |
| `ANDROID_KEYSTORE_PASSWORD` | пароль keystore |
| `ANDROID_KEY_PASSWORD` | пароль ключа |

**Зберігайте keystore-файл і паролі в надійному місці** — якщо їх втратити, наступні оновлення
застосунку доведеться підписувати вже іншим ключем, а це означає, що користувачам треба буде
спочатку видалити стару версію застосунку.

### Локальна збірка (за потреби)

```bash
pip install "flet==0.22.0" yt-dlp
flet build apk
```

Готовий `.apk` з'явиться в `build/apk/`.

## Дозволи (permissions)

- `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE` — потрібні для збереження завантажених треків
  у публічну папку "Завантаження".

## Відомі обмеження

- **Формат тільки `.m4a`, не `.mp3`.** Конвертація в mp3 вимагає `ffmpeg`, якого немає на Android,
  і сучасна система забороняє виконання довільних бінарників, завантажених у рантаймі. `.m4a` — це
  сучасний формат із тією ж якістю звуку, який відтворюється практично всіма плеєрами.
- **Прослуховування "прев'ю" відкриває YouTube**, а не грає звук усередині застосунку — вбудований
  аудіо-плеєр Flet виявився нестабільним на Android у цій збірці, тож натомість використовується
  надійніший системний механізм відкриття посилань.
- Якщо на пристрої немає доступу до публічної папки "Завантаження" (рідкісний випадок, залежить від
  версії Android і виробника), файли зберігаються у внутрішню папку самого застосунку.
